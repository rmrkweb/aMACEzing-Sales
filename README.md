# aMACEzing Sales

Manage your business. Grow your sales.

aMACEzing Sales is an Android app for recording orders, quotations, products and customers, and tracking sales and profit across your businesses.

## Download

Get the latest APK from the [Releases](../../releases/latest) page and install it on your Android phone. The app checks for updates every time it starts, and a newer version must be installed before you can continue.

## Features & User Guide

Learn what the app can do and how to use it: businesses, inventory, quotations, sales and payments, the dashboard, reports, importing data, cloud backup and security.

Read the full guide in [Features And User Guide](FeaturesAndUserGuide.md). The same guide is available inside the app: tap the **?** icon at the top right.
