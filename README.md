# aMACEzing Sales

Manage your business. Grow your sales.

aMACEzing Sales is an Android app for recording orders, quotations, products and customers,
and tracking sales and profit across your businesses.

## Download

Get the latest APK from the [Releases](../../releases/latest) page and install it on your
Android phone. After the first install the app can update itself from **About > Check for updates**.

## Source code

The source code is private. This repository only hosts public releases and the tip QR image.
